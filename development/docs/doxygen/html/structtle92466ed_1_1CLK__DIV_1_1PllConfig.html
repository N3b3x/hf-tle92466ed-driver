Detailed Description

Compute the divider pair (R,N) for a given external fCLK aiming at 28 MHz. Simple heuristic: set R=0 (no reference division) and N=(28e6/fCLK)-1. Caller should check fCLK is in the supported 1\u20138 MHz range.
