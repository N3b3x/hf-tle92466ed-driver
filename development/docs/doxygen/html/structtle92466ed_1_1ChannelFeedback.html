Detailed Description

High-resolution per-channel feedback snapshot (Phase 6).

Populated by ReadChannelFeedback(). Average current uses the FB_I_AVG mantissa ratio with TP_MANT from FB_DC — not FB_I_AVG_s16 (see GetCalibrationAvgCurrent_mA()).
