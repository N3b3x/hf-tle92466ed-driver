Detailed Description

GLOBAL_DIAG2 register bit definitions (datasheet Rev 1.2 §5.3.2.7).

TLE92466ED has no OTP_ECC_WARN / REG_ECC_WARN bits. Successful single-bit ECC correction is silent. Only uncorrectable multi-bit flips set the ERR bits.

  • REG_ECC_ERR disables power stages and forces Config Mode (§4.9.7).
  • OTP_ECC_ERR is factory OTP content; write-1-to-clear twice. It re-asserts if the cells stay corrupt and does not by itself force Config Mode.
  • OTP_VIRGIN must always be 0 (1 = unprogrammed OTP address).
