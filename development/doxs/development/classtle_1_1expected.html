Detailed Description

template<typename T, typename E>
class tle::expected< T, E >

Expected type — holds either a value of type T or an error of type E.

Template Parameters
TValue type
EError type

Stores both members (like tmc51x0::Result<T>). This is acceptable because all types used in this driver are small and trivially copyable.
