Detailed Description

Channel CTRL register bit definitions.

Bit Map:
* Bit 14    : OLSG_WARN_EN      - OLSG warning enable
* Bits 13-9 : OLSG_WARN_WINDOW  - OLSG warning window
* Bit 8     : PWM_PERIOD_CALC_MODE - PWM period calc mode
* Bits 7-0  : MIN_INT_THRESH    - Minimum integrator threshold
*

constexpr uint8_t tle92466ed::CH_CTRL_REG::MIN_INT_THRESH_CEIL = 12u
constexpr

Largest MIN_INT_THRESH compatible with the Autolimit constraint.

Datasheet §4.6.2.3 requires AUTO_LIM_VALUE_ABS > MIN_INT_THRESH + 3. With INTEGRATOR_LIMIT left at its POR AUTO_LIM_VALUE_ABS of 16 that caps MIN_INT_THRESH at 12.

◆ MIN_INT_THRESH_FLOOR

constexpr uint8_t tle92466ed::CH_CTRL_REG::MIN_INT_THRESH_FLOOR = 2u
constexpr

Smallest MIN_INT_THRESH that keeps the ICC power stage switching.

Datasheet §4.6.2.4: the effective integrator threshold is referenced to the lowest deviation integral captured during the on-phase, so it can go negative. When it does, "the integrated current deviation could not exceed the zero level and therefore the power stage would not switch on anymore" — the channel stays enabled with its setpoint intact while the load current silently goes to zero. The datasheet's remedy is to program MIN_INT_THRESH greater than 1.

The POR value is 0, so a channel left unconfigured is exposed to this.
