Detailed Description

SPI transaction configuration.

Defines the configuration parameters for SPI communication. CPOL=0, CPHA=1 (SPI Mode 1) for TLE92466ED

From TLE92466ED datasheet: "The falling edge of CSN indicates the beginning of a data access. Data is sampled in on line SI at the falling edge of SCK and shifted out on line SO at the rising edge of SCK. Each access must be terminated by a rising edge of CSN."
