Detailed Description

FB_PERIOD_MIN_MAX decoder.

Per datasheet \u00a75.3.3.23 p.106. Reports the minimum and maximum PWM period observed during the last measurement window in 256-cycle units of fSYS: bits 9:0 PERIOD_MIN T_MIN = PERIOD_MIN * 256 / fSYS bits 19:10 PERIOD_MAX T_MAX = PERIOD_MAX * 256 / fSYS
