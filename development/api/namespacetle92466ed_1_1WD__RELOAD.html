Detailed Description

WD_RELOAD register bit definitions.

SPI Watchdog Counter Reload Register. The watchdog counter is decremented with fSPI,WD. If it reaches 0, SPI_WD_ERR is set and the device enters Config Mode. The register must be reloaded periodically.

Bit Map:
* Bits 15-11: Reserved
* Bits 10-0 : WD_TIME - Reload value (11-bit)
*
Formula:
<WD_TIME> = rounddown( t_SPI_WD * f_SYS / 2^14 )
Timeout:
t_SPI_WD = <WD_TIME> / f_SPI_WD

Default: 0x0001
