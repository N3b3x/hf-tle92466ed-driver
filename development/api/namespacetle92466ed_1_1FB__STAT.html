Detailed Description

FB_STAT register bit definitions.

General feedback and status information.

Warning
FB_STAT is a 22-bit reply register. INIT_DONE (21) and SPI_WD_ERR (20) sit above bit 15, so a caller that narrows the ReadRegister result to uint16_t silently loses them and reads INIT_DONE as 0 forever. Keep these masks 32-bit.

Bit positions per datasheet Rev. 1.2 (2022-02-01) §5.3.2.21, Table 23. Reset value is 0x200638 — note INIT_DONE is set out of reset.
