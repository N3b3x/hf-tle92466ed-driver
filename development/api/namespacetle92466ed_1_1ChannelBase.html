Detailed Description

Per-channel register base addresses.

Each channel has its own set of registers at a specific base address. Per datasheet Table 25 (Register Address Space - Channel):

  • CH0: 0x0040
  • CH1: 0x0050
  • CH2: 0x0060
  • CH3: 0x0070
  • CH4: 0x0020
  • CH5: 0x0030

Note: Channels are NOT in sequential order. CH4 and CH5 have lower addresses.
