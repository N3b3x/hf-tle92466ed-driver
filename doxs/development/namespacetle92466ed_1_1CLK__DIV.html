Detailed Description

CLK_DIV bit definitions.

Per datasheet \u00a75.3.2.16 p.71. Selects between external clock and the internal oscillator and configures the PLL generating fSYS from the external clock (when EXT_CLK=1): bit 15 EXT_CLK 0 = internal oscillator, 1 = external + PLL bits 14:9 PLL_REFDIV Reference divider R (fREF = fCLK / (R+1)) bits 8:0 PLL_FBDIV Feedback divider N (fSYS = fREF * (N+1))

Resulting system clock must equal 28 MHz \u00b1 tolerances for ICC math to be valid. Typical external clock is 4 or 8 MHz.
