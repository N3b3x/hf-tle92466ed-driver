Detailed Description

SFF_BIST bit definitions.

Per datasheet \u00a75.3.2.18 p.74. Triggers the built-in safe-state logic-BIST and surfaces the result status: bit 0 SFF_BIST_EN Start / run BIST (write 1 to trigger) bit 1 SFF_BIST_DONE 1 = BIST completed bit 2 SFF_BIST_FAIL 1 = BIST detected a stuck-at / logic fault bit 3 SFF_BIST_UERR 1 = Uncorrectable register error during BIST bit 4 SFF_BIST_CERR 1 = Correctable register error during BIST
